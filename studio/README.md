# ParadoXSoftware app

See the [repository README](../README.md) for Firebase login, company collections, live personal-project links, development, authorization tests, and GitHub Pages deployment.

The app now uses Firebase Authentication and Firestore directly. `npm run dev` starts Vite, and `npm run build` / `npm run build:pages` build the GitHub Pages app. Existing starter files for the earlier server-backed version are not used for catalog editing or deployment.
